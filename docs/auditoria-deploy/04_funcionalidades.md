## 3. Contrato API-Desktop

- Versões declaradas: API `0.11.0` (`config.py:10`), contrato `v1`, banco esperado `20261109_0047`, `MINIMUM_DESKTOP_VERSION 2.5.2`, `RECOMMENDED 2.7.0`, `MAXIMUM None`. Desktop `2.9.0`, `APP_API_CONTRACT_VERSION v1`, `MINIMUM_API_VERSION 0.11.0`, build `2026.10.14` (não atualizado).
- Desktop envia `X-Client-Version` em toda requisição (`app/integrations/api/client.py:35`). O preflight (antes do login) checa: banco compatível, desktop >= mínimo, desktop <= máximo (se houver), recursos obrigatórios, contrato.
- `ClientVersionMiddleware` (`api/app/core/client_version_middleware.py`): desligado por padrão. Ligado, devolve 426 `CLIENT_VERSION_UNSUPPORTED` para ausência/formato inválido/versão < mínimo; só trata o mínimo (o máximo é só preflight do Desktop). Isentos: health, version, compatibility, maintenance, `/integrations/almox`. Com o default atual, na prática só o preflight do Desktop protege.
- Canal/promoção (`api/app/channels`, `api/app/updates`): sem alteração nesta branch (diff vazio). Releases são por número de versão e imutáveis: reforça o achado 1.
